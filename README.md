GeoMarket Intelligence

Platforma webowa do analizy danych finansowych i geopolitycznych.

Technologie:
- React + Vite
- Tailwind CSS
- FastAPI / backend
- MySQL
- AI / LLM
- Kafka
- Spark
- Delta Lake

Struktura:
frontend - interfejs użytkownika
backend - API i baza danych
ai - moduł AI i analiza danych
docs - dokumentacja projektu
